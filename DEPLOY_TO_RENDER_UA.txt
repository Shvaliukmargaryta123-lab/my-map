Як опублікувати карту, щоб відкривати її на iPhone через Safari

1. На комп’ютері відкрий https://render.com і створи акаунт.
2. Завантаж проєкт у GitHub (створи новий репозиторій і додай усі файли цієї папки).
3. У Render обери New → Web Service і підключи цей GitHub-репозиторій.
4. Render має визначити Python. Start Command: python server.py
5. Натисни Deploy.
6. Після розгортання Render видасть адресу виду https://назва.onrender.com
7. Відкрий цю адресу на iPhone у Safari. Можеш натиснути «Поділитися» → «На початковий екран».

Важливо:
- Це не App Store-застосунок, а вебсайт, який працює у Safari.
- Сервер потрібен, бо карта звертається до API та Telegram.
- Безкоштовний хостинг може засинати, тому перше відкриття іноді повільне.
- Дані карти залежать від зовнішніх API/джерел і можуть тимчасово не завантажуватися.
